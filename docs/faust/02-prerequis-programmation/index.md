# Phase 2 - Prérequis Programmation

Durée estimée : 1-2 mois

Cette phase couvre les fondations en programmation nécessaires avant d'aborder Faust : paradigme fonctionnel, bases de C++ (pour lire le code généré) et installation de l'environnement de développement.

## Fiches de cette phase

| # | Fiche | Description |
| - | ----- | ----------- |
| 01 | [Programmation fonctionnelle - concepts](01-programmation-fonctionnelle-concepts.md) | Fonctions pures, composition, HOF, récursion, immutabilité, Arrows |
| 02 | [C++ : notions essentielles](02-cpp-notions-essentielles.md) | Compilation, types, pointeurs, classes, CMake, lire du C++ généré |
| 03 | [Environnement et outils](03-environnement-outils.md) | Faust CLI, JACK, faust2xxx, VS Code, faust2svg, Git |
