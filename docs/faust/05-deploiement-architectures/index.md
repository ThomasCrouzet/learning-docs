# Phase 5 - Déploiement et Architectures

Durée estimée : 2-3 mois

Cette phase couvre le déploiement du code Faust vers toutes les cibles : plugins audio (VST/AU/LV2), applications standalone, applications web et mobiles, et systèmes embarqués.
