# Phase 1 - Fondamentaux Acoustique

Durée estimée : 2-3 mois

Cette phase pose les bases scientifiques indispensables pour comprendre le traitement du signal audio : acoustique, audio numérique, mathématiques du DSP et théorie de la synthèse sonore.

## Fiches de cette phase

| # | Fiche | Description |
| - | ----- | ----------- |
| 01 | [Acoustique et psychoacoustique](01-acoustique-psychoacoustique.md) | Ondes, fréquence, amplitude, timbre, spectre harmonique, Fletcher-Munson |
| 02 | [Audio numérique et théorie du signal](02-audio-numerique-theorie-signal.md) | Nyquist-Shannon, échantillonnage, quantification, PCM, FFT, latence |
| 03 | [Mathématiques pour le DSP](03-mathematiques-dsp.md) | Nombres complexes, trigonométrie, Fourier, transformée en Z, pôles/zéros |
| 04 | [Synthèse sonore - théorie](04-synthese-sonore-theorie.md) | Additive, soustractive, FM, modélisation physique, granulaire, ADSR |
