# Phase 3 - Langage Faust Fondamentaux

Durée estimée : 2-3 mois

Cette phase couvre le coeur du langage Faust : syntaxe, les cinq opérateurs de composition (le concept central), les interfaces utilisateur et la gestion de la mémoire et des délais.

## Fiches de cette phase

| # | Fiche | Description |
| - | ----- | ----------- |
| 01 | [Syntaxe et sémantique de base](01-syntaxe-semantique-base.md) | `process`, `import`, signaux comme fonctions du temps, primitives |
| 02 | [Les cinq opérateurs de composition](02-cinq-operateurs-composition.md) | `:` séquentiel, `,` parallèle, `<:` split, `:>` merge, `~` récursif |
| 03 | [Interfaces utilisateur (UI)](03-interfaces-utilisateur-ui.md) | hslider, vslider, nentry, button, checkbox, groupes, métadonnées |
| 04 | [Mémoire et délais](04-memoire-delais.md) | `'` (prime), `@` délai, `~` feedback, rdtable/rwtable, buffers circulaires |
