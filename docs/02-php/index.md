# PHP

Ce module couvre les fondamentaux du langage PHP. Tu partiras de la syntaxe de base pour progresser jusqu'à la programmation orientée objet, les namespaces et les attributs. Ces connaissances sont indispensables pour aborder Symfony.

**Prérequis** : Module Docker terminé.
