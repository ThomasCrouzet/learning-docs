# Phase 6 - Large Language Models

Durée estimée : 2-3 mois

Cette phase couvre l'écosystème des LLM : architecture interne, prompt engineering, RAG, fine-tuning et évaluation.

## Fiches de cette phase

| # | Fiche | Description |
| - | ----- | ----------- |
| 01 | [Architecture et fonctionnement des LLM](01-architecture-fonctionnement-llm.md) | Decoder-only, KV-cache, scaling laws, RLHF, DPO |
| 02 | [Prompt engineering et context engineering](02-prompt-engineering-context-engineering.md) | Zéro/few-shot, CoT, ReAct, system prompts, context window |
| 03 | [RAG - Retrieval-Augmented Generation](03-rag-retrieval-augmented-generation.md) | Embeddings, vector stores, chunking, hybrid search, reranking |
| 04 | [Fine-tuning et adaptation de modèles](04-fine-tuning-adaptation-modeles.md) | LoRA, QLoRA, PEFT, quantization (GPTQ/AWQ), datasets d'instruction |
| 05 | [Évaluation des LLM](05-evaluation-llm.md) | Benchmarks, LLM-as-Judge, red-teaming, hallucinations, golden sets |
