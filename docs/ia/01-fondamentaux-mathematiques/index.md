# Phase 1 - Fondamentaux Mathématiques

Durée estimée : 2-3 mois

Cette phase pose les bases mathématiques indispensables pour comprendre le machine learning et le deep learning : algèbre linéaire, calcul différentiel, probabilités et théorie de l'information.

## Fiches de cette phase

| # | Fiche | Description |
| - | ----- | ----------- |
| 01 | [Algèbre linéaire](01-algebre-lineaire.md) | Vecteurs, matrices, produit matriciel, espaces vectoriels, SVD |
| 02 | [Calcul différentiel et optimisation](02-calcul-differentiel-optimisation.md) | Dérivées, gradient, chain rule, descente de gradient, Adam |
| 03 | [Probabilités et statistiques](03-probabilites-statistiques.md) | Distributions, Bayes, espérance/variance, MLE, biais-variance |
| 04 | [Théorie de l'information](04-theorie-information.md) | Entropie, cross-entropy, divergence KL, information mutuelle |
