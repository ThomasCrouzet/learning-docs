# Phase 3 - Machine Learning Classique

Durée estimée : 2-3 mois

Cette phase couvre les algorithmes fondamentaux du machine learning : apprentissage supervisé et non supervisé, méthodologie de sélection de modèles et usage approfondi de scikit-learn.

## Fiches de cette phase

| # | Fiche | Description |
| - | ----- | ----------- |
| 01 | [Apprentissage supervisé](01-apprentissage-supervise.md) | Régression linéaire/logistique, arbres, Random Forest, XGBoost |
| 02 | [Apprentissage non supervisé](02-apprentissage-non-supervise.md) | K-Means, DBSCAN, PCA, t-SNE, UMAP |
| 03 | [Sélection de modèles et méthodologie](03-selection-modeles-methodologie.md) | Cross-validation, biais/variance, hyperparamètres, métriques |
| 04 | [scikit-learn en profondeur](04-scikit-learn-profondeur.md) | Pipelines, transformers custom, ColumnTransformer, MLflow |
