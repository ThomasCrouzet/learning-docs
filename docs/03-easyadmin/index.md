# EasyAdmin

Ce module couvre la création d'une interface d'administration complète avec EasyAdmin, le bundle Symfony de référence pour les back-offices. Tu apprendras à générer des CRUD, sécuriser l'accès, gérer les utilisateurs, personnaliser les champs et l'apparence.

**Prérequis** : Avoir complété le cursus [Docker](../01-docker/index.md).

## Fiches

| # | Fiche | Description |
| - | ----- | ----------- |
| 01 | [Installer EasyAdmin](01-easyadmin-installation.md) | Installer et configurer le bundle EasyAdmin |
| 02 | [Champs avancés EasyAdmin](02-easyadmin-champs-avances.md) | Personnaliser les champs des formulaires d'administration |
| 03 | [Authentification EasyAdmin](03-easyadmin-authentification.md) | Sécuriser l'accès au tableau de bord EasyAdmin |
| 04 | [Gestion des utilisateurs](04-easyadmin-utilisateurs.md) | Gérer les utilisateurs et les rôles depuis EasyAdmin |
| 05 | [Images et filtres](05-easyadmin-images-filtres.md) | Gérer l'upload d'images et les filtres de recherche |
| 06 | [Actions personnalisées](06-easyadmin-actions-personnalisees.md) | Créer des actions personnalisées dans EasyAdmin |
| 07 | [Personnalisation visuelle](07-easyadmin-personnalisation-visuelle.md) | Adapter l'apparence du tableau de bord EasyAdmin |

!!! tip "Parcours recommandé"
    Suis les fiches dans l'ordre numérique. Les fiches construisent progressivement le back-office EasyAdmin, de l'installation à la personnalisation visuelle avancée.
