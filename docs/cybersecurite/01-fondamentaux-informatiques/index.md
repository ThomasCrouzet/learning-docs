# Phase 1 - Fondamentaux Informatiques

Durée estimée : 2-3 mois

Cette phase pose les bases indispensables : architecture matérielle, systèmes d'exploitation, réseaux et programmation.

## Fiches de cette phase

| # | Fiche | Description |
| - | ----- | ----------- |
| 01 | [Architecture matérielle](01-architecture-materielle.md) | CPU, mémoire, bus, boot process, rings |
| 02 | [Systèmes d'exploitation](02-systemes-exploitation.md) | Processus, fichiers, permissions, Linux/Windows |
| 03 | [Réseaux et protocoles](03-reseaux-protocoles.md) | OSI, TCP/IP, routage, switching, Wireshark |
| 04 | [Programmation et scripting](04-programmation-scripting.md) | Python, Bash, C, JavaScript pour la sécurité |
