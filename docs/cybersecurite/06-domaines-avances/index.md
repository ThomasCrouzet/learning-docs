# Phase 6 - Domaines Avancés et Spécialisations

Durée estimée : 3-4 mois

Cette phase couvre les domaines spécialisés de la cybersécurité : cloud, environnements industriels, intelligence artificielle, IoT/mobile et DevSecOps. Ces sujets sont recherchés sur le marché ; les fiches donnent une base de lecture et de vocabulaire, pas une qualification de poste à elles seules.

## Prérequis

- Phases 1 à 3 complètes (fondamentaux informatiques, sécurité, compétences intermédiaires)
- Phase 4 (offensive) ou Phase 5 (défensive) selon la spécialisation visée

## Fiches de cette phase

| # | Fiche | Description |
| - | ----- | ----------- |
| 01 | [Sécurité Cloud](01-securite-cloud.md) | AWS, Azure, GCP, responsabilité partagée, IAM, conteneurs, IaC |
| 02 | [Sécurité OT/ICS/SCADA](02-securite-ot-ics-scada.md) | Environnements industriels, Purdue Model, protocoles, IEC 62443 |
| 03 | [Sécurité de l'IA et Machine Learning](03-securite-ia-machine-learning.md) | Adversarial ML, sécurité des pipelines, AI for security, deepfakes |
| 04 | [Sécurité Mobile et IoT](04-securite-mobile-iot.md) | Android/iOS, analyse APK, firmware, hardware hacking, radio |
| 05 | [DevSecOps et Sécurité Applicative](05-devsecops.md) | Shift-left, CI/CD security, SAST/DAST/SCA, supply chain, SBOM |

## Parcours recommandé

Les fiches peuvent être étudiées dans l'ordre proposé ou selon tes intérêts de spécialisation :

- **Profil Cloud/DevOps** : fiches 01 puis 05
- **Profil industriel** : fiche 02
- **Profil recherche/data** : fiche 03
- **Profil pentest/hardware** : fiche 04
- **Profil développeur sécurité** : fiches 05 puis 01
