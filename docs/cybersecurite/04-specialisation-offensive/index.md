# Phase 4 - Spécialisation Offensive (Pentest / Red Team)

Durée estimée : 4-6 mois

Cette phase couvre les techniques offensives utilisées en test d'intrusion professionnel : méthodologie, exploitation, Active Directory, sécurité web avancée et certifications reconnues.

## Prérequis

- Phase 1 - Fondamentaux Informatiques (complète)
- Phase 2 - Fondamentaux Sécurité (complète)
- Phase 3 - Compétences Intermédiaires (complète)
