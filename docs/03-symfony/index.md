# Symfony

Ce module couvre le framework Symfony. Tu apprendras l'architecture MVC, le système de routes et contrôleurs, les templates Twig, l'ORM Doctrine pour la base de données, et la personnalisation d'EasyAdmin. C'est le cœur de la stack technique.

**Prérequis** : Module PHP terminé.

Les fiches 09 à 10 couvrent les formulaires et EasyAdmin. Les fiches 11 à 21 abordent les sujets avancés : validation, sécurité, services, événements, commandes, API, tests, workflow, Messenger, traductions et pagination.
