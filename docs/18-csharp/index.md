# C\#

Ce cursus couvre les fondamentaux du langage C# et de la plateforme .NET : syntaxe de base, types, programmation orientée objet, collections, LINQ et gestion des erreurs. À la fin de ce cursus, tu seras capable d'écrire des applications console C# structurées et maintenables.

## Prérequis

- Avoir terminé le [cursus Java](../epitech/01-java/index.md) (les concepts de POO sont similaires entre Java et C#)
