# HTML / CSS

Ce module couvre les bases du développement web côté client : structurer une page avec HTML, appliquer des styles avec CSS, créer des mises en page modernes avec Flexbox et Grid, et ajouter des animations.

## Fiches du module

| # | Fiche | Description |
| - | ----- | ----------- |
| 1 | [Structure HTML](01-structure-html.md) | Balises, attributs et squelette d'une page |
| 2 | [HTML sémantique](02-html-semantique.md) | Balises sémantiques et accessibilité |
| 3 | [Formulaires](03-formulaires.md) | Champs de saisie, validation et soumission |
| 4 | [CSS de base](04-css-base.md) | Sélecteurs, propriétés et cascade |
| 5 | [Flexbox](05-flexbox.md) | Mise en page flexible en une dimension |
| 6 | [CSS Grid](06-css-grid.md) | Mise en page en grille à deux dimensions |
| 7 | [Animations CSS](07-animations-css.md) | Transitions, transformations et keyframes |

!!! note "Parcours recommandé"
    **Prérequis** : Aucun. Suis les fiches dans l'ordre : d'abord la structure HTML, puis le CSS pour la mise en forme.
