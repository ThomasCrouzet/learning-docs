# Compétences métier

Ces cursus relient le code à des activités concrètes de projet : comprendre un besoin, planifier le travail, déployer, développer et concevoir l'architecture d'un système d'information.

Ce n'est **pas** un titre, ni une formation diplômante. Chaque module est un cours autonome, à relier ensuite aux cursus techniques du wiki.

## Cursus du module

| # | Cursus | Description |
| - | ------ | ----------- |
| 01 | [Besoins utilisateurs](01-besoins-utilisateurs/index.md) | 3 fiches - cahier des charges, étude de marché, faisabilité |
| 02 | [Pilotage de projet](02-pilotage-projet/index.md) | 3 fiches - méthodologies agiles, gestion d'équipe, planification |
| 03 | [Cloud computing](03-cloud-computing/index.md) | 5 fiches - introduction, pentest, IaC, CI/CD, Kubernetes |
| 04 | [Développement logiciel](04-developpement-logiciel/index.md) | 4 fiches - architecture web, sécurité, tests, mobile |
| 05 | [Architecture SI](05-architecture-si/index.md) | 4 fiches - réseau, supervision, sécurité, audit |

!!! note "Organisation"
    Chaque cursus peut être étudié indépendamment. L'ordre 01 → 05 suit le déroulement d'un projet, du besoin initial à l'architecture.
