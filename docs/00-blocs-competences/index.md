# Certification RNCP

Ce module regroupe des **fiches préparatoires** autour de la certification RNCP38114 - Architecte de Systèmes d'Information (ETNA). Les 5 blocs de compétences couvrent l'analyse des besoins, le pilotage de projet, le cloud computing, le développement logiciel et l'architecture SI.

!!! note "Périmètre honnête"
    Ces fiches **ne délivrent pas** la certification et **ne remplacent pas** la formation ni les évaluations du certificateur (ETNA). Elles aident à comprendre les thèmes du référentiel. La validation officielle se fait uniquement via le parcours et les jurys du certificateur.
    Sur France Compétences, **RNCP38114** (échéance d'enregistrement 18-10-2026) est indiquée comme **remplacée par RNCP42634** ("Architecte des systèmes d'information", échéance 17-07-2031).
    Vérifie le code actif et les modalités sur le site officiel avant toute inscription (voir aussi la fiche de présentation).
