# BC01 - Besoins utilisateurs

Ce bloc couvre l'analyse des besoins utilisateurs : rédaction d'un cahier des charges, réalisation d'une étude de marché et évaluation de la faisabilité d'un projet.

## Fiches du module

| # | Fiche | Description |
| - | ----- | ----------- |
| 01 | [Cahier des charges](01-cahier-des-charges.md) | Rédiger un cahier des charges fonctionnel et technique |
| 02 | [Étude de marché](02-etude-de-marche.md) | Analyser le marché et la concurrence |
| 03 | [Analyse de faisabilité](03-analyse-faisabilite.md) | Évaluer la faisabilité technique et économique |

!!! tip "Parcours recommandé"
    Suis les fiches dans l'ordre numérique. Le cahier des charges pose le cadre, l'étude de marché le contextualise, et l'analyse de faisabilité le valide.
