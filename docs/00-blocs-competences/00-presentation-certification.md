## Concepts

### Qu'est-ce que la certification RNCP38114 ?

**Définition** : La certification RNCP38114 "Architecte de Systèmes d'Information" est une **certification professionnelle** de niveau 7 (équivalent Bac+5/Master) inscrite au RNCP, reconnue par l'État français, délivrée par l'ETNA (École Tech Numériques Appliquées).

**Le problème que cette certification résout** :

Sans certification reconnue, voici les problèmes rencontrés :

1. **Pas de reconnaissance officielle** : Les employeurs ne peuvent pas vérifier tes compétences de manière standardisée.
2. **Pas d'équivalence** : Impossible de faire valoir ton niveau dans d'autres pays ou pour des concours.
3. **Pas de cadre** : Difficile de savoir quelles compétences acquérir pour devenir architecte SI.

**Comment cette certification résout ces problèmes** :

| Problème | Solution apportée par la certification |
| -------- | -------------------------------------- |
| Pas de reconnaissance officielle | Inscrite au RNCP, reconnue par l'État |
| Pas d'équivalence | Niveau 7 = Master, reconnu en Europe |
| Pas de cadre | 5 blocs de compétences définis clairement |

**Analogie concrète** : Imagine un permis de conduire. Sans permis, tu peux savoir conduire, mais personne ne peut le vérifier officiellement. Avec le permis, tu as une preuve reconnue partout. Cette certification est le "permis" de l'architecte SI.

**Ce que cette certification n'est PAS** :

- Cette certification n'est pas un diplôme universitaire. C'est une certification professionnelle, orientée vers les compétences métier.
- Cette certification n'est pas obligatoire pour travailler en informatique. Mais elle facilite l'accès à certains postes.
- **Ces fiches du wiki ne sont pas la certification.** Les lire ne te rend pas certifié. Seul le certificateur (ETNA) peut délivrer le titre après ses évaluations officielles.

!!! note "Périmètre de ce module"
    Les fiches de `00-blocs-competences/` sont une **préparation pédagogique** aux thèmes du référentiel (concepts, méthodes, exemples). Elles n'équivalent pas au programme complet d'une école, ni aux projets et jurys de validation. Pour te certifier, tu dois suivre le parcours du certificateur.

### Qu'est-ce qu'un bloc de compétences ?

**Définition** : Un bloc de compétences est un ensemble cohérent de compétences professionnelles qui peut être évalué et validé de manière indépendante.

**Le problème que les blocs de compétences résolvent** :

Sans découpage en blocs, voici les problèmes rencontrés :

1. **Tout ou rien** : Si tu échoues à une partie, tu perds tout.
2. **Pas de spécialisation** : Impossible de choisir une orientation.
3. **Validation floue** : Difficile de savoir exactement ce qui est évalué.

**Comment les blocs résolvent ces problèmes** :

| Problème | Solution |
| -------- | -------- |
| Tout ou rien | Chaque bloc est validé indépendamment |
| Pas de spécialisation | Des blocs "tronc commun" + des blocs de spécialisation |
| Validation floue | Chaque bloc a ses propres critères d'évaluation |

**Analogie concrète** : Imagine un Lego. Chaque bloc de compétences est comme une pièce de Lego. Tu peux les assembler pour construire ton profil. Les pièces du tronc commun sont obligatoires (la base), et tu choisis tes pièces de spécialisation (le toit).

## Les 5 Blocs de Compétences

### Vue d'ensemble

| Bloc | Nom | Type |
| ---- | --- | ---- |
| BC01 | Recueillir les besoins utilisateurs et les traduire en stratégie technique | Tronc commun |
| BC02 | Piloter un projet d'architecture d'une solution numérique | Tronc commun |
| BC03 | Construire une architecture "edge computing" ou "cloud computing" | Spécialisation Système/Réseau |
| BC04 | Conduire le développement d'une application logicielle | Spécialisation Logicielle |
| BC05 | Concevoir une architecture pour l'infrastructure d'un SI | Tronc commun |

---

### BC01 - Recueillir les besoins utilisateurs

**Objectif** : Savoir analyser les besoins d'un client ou d'une entreprise et les traduire en spécifications techniques.

**Compétences principales** :

- Rédiger un cahier des charges technique
- Réaliser une étude de marché et une veille concurrentielle
- Évaluer la faisabilité d'un projet
- Cartographier les systèmes d'information existants

**Évaluations** :

- Rédaction d'un cahier des charges technique
- Dossier d'étude de marché (5-10 pages)
- Soutenance de dossier

**Fiches associées** : `BC01-besoins-utilisateurs/`

---

### BC02 - Piloter un projet d'architecture

**Objectif** : Savoir gérer un projet informatique de A à Z, en utilisant les méthodes agiles et en coordonnant une équipe.

**Compétences principales** :

- Utiliser les méthodologies agiles (Scrum, Kanban)
- Manager des équipes pluridisciplinaires
- Établir une roadmap et planifier les livrables
- Argumenter et justifier les décisions techniques

**Évaluations** :

- Pilotage d'un projet de fin d'année
- Rapport sur la gestion d'équipe

**Fiches associées** : `BC02-pilotage-projet/`

---

### BC03 - Construire une architecture Cloud (Spécialisation Système/Réseau)

**Objectif** : Savoir concevoir et déployer des infrastructures cloud (edge computing, cloud computing).

**Compétences principales** :

- Comprendre les architectures cloud (IaaS, PaaS, SaaS)
- Réaliser des tests d'intrusion (pentest)
- Automatiser le déploiement avec l'Infrastructure as Code
- Mettre en place du déploiement continu (CI/CD)
- Maîtriser Kubernetes

**Évaluations** :

- Rapport de pentest sur un système d'information
- Développement d'une solution déployée sur le Cloud
- Automatisation d'infrastructure as code
- Conception d'une architecture de base de données scalable

**Fiches associées** : `BC03-cloud-computing/`

---

### BC04 - Conduire le développement logiciel (Spécialisation Logicielle)

**Objectif** : Savoir développer et maintenir des applications web et mobiles de qualité.

**Compétences principales** :

- Développer un serveur web HTTP performant
- Implémenter la sécurité (SSL, JWT, hashage)
- Mettre en place des tests et de la qualité logicielle
- Développer des applications mobiles et desktop

**Évaluations** :

- Développement d'un serveur web
- Développement d'une application mobile/desktop responsive
- Définition d'une roadmap avec KPI de qualité

**Fiches associées** : `BC04-developpement-logiciel/`

---

### BC05 - Concevoir une architecture SI

**Objectif** : Savoir concevoir et sécuriser l'infrastructure d'un système d'information.

**Compétences principales** :

- Configurer des infrastructures réseau
- Mettre en place de la supervision et du monitoring
- Assurer la sécurité du système d'information
- Réaliser des audits de sécurité

**Évaluations** :

- Configuration sécurisée d'installations réseau
- Maîtrise des protocoles de routage
- Formation des collaborateurs à la sécurité (rapport + soutenance)
- Audit de sécurité d'un SI

**Fiches associées** : `BC05-architecture-si/`

## Comment Valider la Certification ?

### Blocs à valider

Pour obtenir la certification complète, tu dois valider :

| Élément | Obligatoire |
| ------- | ----------- |
| BC01 - Besoins utilisateurs | Oui (tronc commun) |
| BC02 - Pilotage projet | Oui (tronc commun) |
| BC05 - Architecture SI | Oui (tronc commun) |
| BC03 - Cloud computing | Oui si spécialisation Système/Réseau |
| BC04 - Développement logiciel | Oui si spécialisation Logicielle |

**En résumé** : 3 blocs de tronc commun + 1 bloc de spécialisation au choix.

### Validation indépendante

Chaque bloc peut être validé de manière autonome. Si tu valides un bloc mais pas les autres, ce bloc reste acquis. Tu peux compléter les autres blocs plus tard.

## Secteurs d'Activité

Après cette certification, tu peux travailler dans :

- **Éditeurs de logiciels** : Concevoir et maintenir des produits logiciels
- **Sociétés de services (ESN/SSII)** : Missions de conseil et développement chez des clients
- **Entreprises utilisatrices** : DSI de grandes entreprises, PME, administrations
- **Fournisseurs d'infrastructure** : Cloud providers, hébergeurs

### Métiers accessibles

| Métier | Description |
| ------ | ----------- |
| Architecte système | Conception de l'architecture globale d'un SI |
| Architecte solution | Conception de solutions techniques pour des projets |
| Expert en systèmes d'information | Conseil et expertise technique |
| Directeur des systèmes d'information | Management de la DSI (avec expérience) |
