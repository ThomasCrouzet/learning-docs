# Cursus UX Design

Cursus transversal en **4 fiches progressives**. Des principes fondamentaux de l'UX jusqu'aux tests utilisateurs, en passant par la création de wireframes et la mise en place d'un design system.

**Durée estimée totale** : 4h15.

**Prérequis** : avoir suivi le cursus [HTML / CSS](../fondamentaux/04-html-css/index.md) pour connaître les bases de la structure web et du CSS.

---

## Vue d'ensemble

| # | Fiche | Description | Durée |
| - | ----- | ----------- | ----- |
| 01 | [Principes UX](01-principes-ux.md) | UX vs UI, heuristiques de Nielsen, accessibilité WCAG, personas, parcours utilisateur | 60 min |
| 02 | [Wireframes et maquettes](02-wireframes-maquettes.md) | Outils (Figma, Excalidraw), wireframes basse et haute fidélité, prototypage, mobile-first | 75 min |
| 03 | [Design system](03-design-system.md) | Composants réutilisables, tokens de design, typographie, palette de couleurs, grille | 60 min |
| 04 | [Tests utilisateurs](04-tests-utilisateurs.md) | Tests d'utilisabilité, A/B testing, métriques UX, feedback loops, itération | 60 min |
