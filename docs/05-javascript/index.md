# JavaScript

Bienvenue dans la section JavaScript du cursus Stack Symfony.

Cette section couvre l'utilisation de JavaScript dans un projet Symfony : gestion des assets avec Webpack Encore, jQuery (legacy, pour le code existant), Stimulus (recommandé pour les nouveaux projets), AssetMapper, et les requêtes AJAX.

## Prérequis

Avant de commencer cette section, tu dois avoir terminé :

- La section **[JavaScript Epitech](../epitech/05-javascript/index.md)** (bases JS, DOM, événements)
- La section **[Symfony](../03-symfony/index.md)** (contrôleurs, routes, templates Twig)
