# Cloud

> **En bref** : Ce cursus couvre les fondamentaux du cloud computing, des modèles de service (IaaS, PaaS, SaaS) au déploiement d'applications complètes, en passant par le compute, le stockage, le réseau, la sécurité IAM, l'Infrastructure as Code avec Terraform et AWS CDK, les bases de données managées, les conteneurs, le monitoring, le serverless et le FinOps. 13 fiches progressives.
