<!-- Format : *[Terme]: Définition courte -->

<!-- Architecture & Patterns -->
*[API]: Application Programming Interface - interface permettant à des programmes de communiquer entre eux
*[REST]: Representational State Transfer - style d'architecture pour les API web basé sur les ressources et les verbes HTTP
*[CRUD]: Create, Read, Update, Delete - les quatre opérations de base sur les données
*[MVC]: Model-View-Controller - pattern d'architecture séparant données, affichage et logique
*[SOLID]: Cinq principes de conception orientée objet : Single Responsibility, Open/Closed, Liskov Substitution, Interface Segregation, Dependency Inversion
*[DDD]: Domain-Driven Design - approche de conception logicielle centrée sur le domaine métier
*[TDD]: Test-Driven Development - méthode de développement où les tests sont écrits avant le code

<!-- Conteneurisation & DevOps -->
*[CLI]: Command-Line Interface - interface en ligne de commande pour interagir avec un programme
*[CI/CD]: Continuous Integration / Continuous Deployment - automatisation des tests et du déploiement à chaque modification du code
*[ORM]: Object-Relational Mapping - bibliothèque qui fait le lien entre les objets du code et les tables de la base de données
*[YAML]: YAML Ain't Markup Language - format de sérialisation de données lisible par l'humain, utilisé pour les fichiers de configuration

<!-- Base de données -->
*[SQL]: Structured Query Language - langage de requête pour interroger et manipuler les bases de données relationnelles
*[SGBD]: Système de Gestion de Base de Données - logiciel qui stocke, organise et permet d'accéder aux données (ex : PostgreSQL)

<!-- Web & Frontend -->
*[DOM]: Document Object Model - représentation en mémoire de la structure HTML d'une page web
*[JSON]: JavaScript Object Notation - format léger d'échange de données, lisible par l'humain et par les machines
*[JSX]: JavaScript XML - extension de syntaxe React qui permet d'écrire du HTML dans du JavaScript
*[SPA]: Single Page Application - application web qui charge une seule page HTML et met à jour dynamiquement le contenu
*[SSR]: Server-Side Rendering - rendu côté serveur où le HTML est généré par le serveur avant l'envoi au navigateur
*[CDN]: Content Delivery Network - réseau de serveurs distribués qui accélère la livraison de contenu web

<!-- JavaScript & TypeScript -->
*[ES6]: ECMAScript 2015 - version majeure de JavaScript introduisant let/const, arrow functions, classes, modules, Promises
*[NPM]: Node Package Manager - gestionnaire de paquets pour Node.js

<!-- PHP & Symfony -->
*[PSR]: PHP Standards Recommendation - ensemble de standards de codage et d'interopérabilité pour PHP

<!-- Sécurité -->
*[OWASP]: Open Web Application Security Project - organisation qui publie les référentiels de sécurité web (Top 10 des vulnérabilités)
*[XSS]: Cross-Site Scripting - vulnérabilité web permettant d'injecter du code JavaScript malveillant dans une page
*[CSRF]: Cross-Site Request Forgery - attaque forçant un utilisateur authentifié à exécuter une action non voulue
*[JWT]: JSON Web Token - standard de jeton d'authentification compact et auto-suffisant

<!-- Cybersécurité -->
*[OSINT]: Open Source Intelligence - renseignement obtenu à partir de sources publiquement accessibles
*[APT]: Advanced Persistent Threat - attaque ciblée et prolongée menée par un acteur sophistiqué
*[SIEM]: Security Information and Event Management - plateforme centralisant les logs de sécurité pour détecter les incidents
*[DFIR]: Digital Forensics and Incident Response - investigation numérique et réponse aux incidents de sécurité
*[CVE]: Common Vulnerabilities and Exposures - identifiant unique attribué à une vulnérabilité de sécurité connue
*[C2]: Command and Control - serveur utilisé par un attaquant pour piloter des machines compromises
*[XDR]: Extended Détection and Response - solution de détection étendue corrélant les données de plusieurs sources de sécurité
*[GRC]: Governance, Risk and Compliance - cadre de gouvernance, gestion des risques et conformité réglementaire

<!-- Intelligence Artificielle -->
*[LLM]: Large Language Model - grand modèle de langage entraîné sur de vastes corpus de texte (ex : GPT, Claude)
*[RAG]: Retrieval-Augmented Generation - technique combinant recherche documentaire et génération de texte par un LLM
*[CNN]: Convolutional Neural Network - réseau de neurones convolutif, spécialisé dans le traitement d'images
*[RNN]: Recurrent Neural Network - réseau de neurones récurrent, adapté au traitement de séquences
*[NLP]: Natural Language Processing - traitement automatique du langage naturel
*[MLOps]: Machine Learning Operations - ensemble de pratiques pour déployer et maintenir des modèles ML en production
*[GPU]: Graphics Processing Unit - processeur graphique utilisé pour accélérer les calculs d'entraînement des modèles
*[GAN]: Generative Adversarial Network - réseau génératif adversaire composé d'un générateur et d'un discriminateur
*[DDSP]: Differentiable Digital Signal Processing - traitement du signal audio intégré dans des réseaux de neurones différentiables
*[LoRA]: Low-Rank Adaptation - technique de fine-tuning efficace qui modifie un petit nombre de paramètres d'un modèle

<!-- Audio / Faust -->
*[DSP]: Digital Signal Processing - traitement numérique du signal audio
*[DAW]: Digital Audio Workstation - station de travail audio numérique (ex : Ableton, Reaper)
*[VST]: Virtual Studio Technology - format de plugin audio pour les DAW
*[MIDI]: Musical Instrument Digital Interface - protocole de communication entre instruments de musique électroniques
*[OSC]: Open Sound Control - protocole réseau pour le contrôle d'instruments et d'applications audio/multimédia
*[FFT]: Fast Fourier Transform - algorithme de transformation rapide de Fourier pour analyser les fréquences d'un signal
*[LV2]: LADSPA Version 2 - format ouvert de plugin audio pour Linux
*[AU]: Audio Unit - format de plugin audio natif sur macOS

<!-- Infrastructure -->
*[RBAC]: Role-Based Access Control - contrôle d'accès basé sur les rôles attribués aux utilisateurs
*[IaC]: Infrastructure as Code - gestion de l'infrastructure via des fichiers de configuration versionnés
*[SOC]: Security Operations Center - centre opérationnel de sécurité qui surveille et analyse les incidents
*[EDR]: Endpoint Detection and Response - solution de détection et réponse sur les terminaux
*[HPA]: Horizontal Pod Autoscaler - composant Kubernetes qui ajuste le nombre de pods selon la charge

<!-- Crypto-monnaies -->
*[DEX]: Decentralized Exchange - plateforme d'échange de crypto-monnaies sans intermédiaire centralisé
*[DeFi]: Decentralized Finance - ensemble de services financiers construits sur des blockchains publiques
*[DAO]: Decentralized Autonomous Organization - organisation dont les règles de gouvernance sont codées dans des smart contracts
*[EVM]: Ethereum Virtual Machine - machine virtuelle qui exécute les smart contracts sur Ethereum
*[NFT]: Non-Fungible Token - jeton numérique unique représentant la propriété d'un actif sur une blockchain
*[MEV]: Maximal Extractable Value - profit que les validateurs peuvent extraire en réordonnant les transactions dans un bloc
*[CBDC]: Central Bank Digital Currency - monnaie numérique émise par une banque centrale
