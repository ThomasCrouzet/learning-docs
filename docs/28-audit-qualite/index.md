# Audit et Qualité

> **En bref** : Reprendre une application en production demande une méthode. Ce cursus te montre comment cartographier une base de code existante, identifier les invariants métier, prioriser les risques, lire le code pour repérer les bugs et formaliser tes découvertes dans des issues utilisables. 6 fiches progressives.

## Prérequis

- Cursus Testing (`09-testing/`, au moins fiche 01)
- Cursus Symfony (notions de routes, contrôleurs, entités)
- Cursus PHP et Doctrine

## Durée totale estimée

~6 heures de lecture et pratique.

## Public visé

Développeur en milieu d'apprentissage ou nouvellement affecté à un projet existant peu testé. La méthode est applicable à toute pile web orientée objet ; les exemples utilisent Symfony et PHP.
