# PostgreSQL

Ce module couvre les bases de PostgreSQL. Tu apprendras à écrire des requêtes SQL pour interroger et croiser des données. Ces connaissances complètent ce que tu as vu avec Doctrine et te permettent de comprendre ce qui se passe sous le capot de l'ORM.

**Prérequis** : Module Symfony terminé (pour le contexte Doctrine).

## Fiches du module

| # | Fiche | Description |
| - | ----- | ----------- |
| 01 | [Introduction à PostgreSQL](01-introduction-postgresql.md) | Découvrir PostgreSQL, se connecter et explorer une base |
| 02 | [Requêtes SELECT](02-requetes-select.md) | Interroger les données avec SELECT, WHERE et ORDER BY |
| 03 | [Jointures](03-jointures.md) | Croiser les données de plusieurs tables avec les jointures |
| 04 | [INSERT, UPDATE, DELETE](04-insert-update-delete.md) | Modifier les données dans les tables |
| 05 | [Fonctions d'agrégation](05-fonctions-agregation.md) | COUNT, SUM, AVG, GROUP BY et HAVING |
| 06 | [Contraintes et index](06-contraintes-index.md) | Protéger l'intégrité des données et optimiser les requêtes |
| 07 | [Sous-requêtes et vues](07-sous-requetes-vues.md) | IN, EXISTS, sous-requêtes corrélées, CREATE VIEW |
| 08 | [Transactions](08-transactions.md) | BEGIN, COMMIT, ROLLBACK, SAVEPOINT, ACID |

!!! tip "Parcours recommandé"
    Suis les fiches dans l'ordre numérique. Les fiches 01 à 03 couvrent les bases (connexion, SELECT, jointures). Les fiches 04 à 06 couvrent la modification de données, l'agrégation et les contraintes. Les fiches 07 et 08 abordent les sous-requêtes, vues et transactions.
